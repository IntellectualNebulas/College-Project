# College-Project

Made for year 2 of Foundation Apprenticeship Software Development Course

This project contains:
Python file handling 
Python JavaScript integration
HTML & CSS Web development
JavaScript Web integration

This project is meant to test our capability as programmers and as a Team. Serving as something worthy of being put on a CV.

The project is an ARG. Where you are a detective put in charge of finding the person who killed Cian Stewart. As the sole detective you must piece together clues and put together evidence to catch the murderer. Two endings are present, a good ending where you catch the killer and are hailed a hero, and the bad ending, where you don’t find the murderer and they walk free to continue their slaughter. Can you find them?

Made by Ciaran, Emma, Lewis and Alex

Python Dependencies:
Flask
python 3
